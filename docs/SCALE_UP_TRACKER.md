# CBOP → Enterprise Scale-Up: Research Tracker

## Why this exists
2026-08-05: decision made to take CBOP from "internal 3-user tool for 5 owned companies" to a **multi-tenant "Super OS" SaaS product** for external SMB/enterprise clients, going international. This tracker holds the research workstreams that feed `docs/Project-Scale-Up-Plan.md` — the actual build plan. Do not start building against this doc; it's the research inbox. Build against `Project-Scale-Up-Plan.md` once it exists.

**Ground truth to reconcile, not ignore:** `CLAUDE.md`'s "Non-negotiable constraints" were written for the single-tenant homeserver era (Postgres+better-auth only, no Redis, n8n-only automations, hardcoded 3-user role model, etc). Every research agent below is instructed to name which of those constraints breaks at real multi-tenant SaaS scale and propose the replacement — not silently violate them. The final plan doc is where those constraint changes get decided explicitly with Bala, not assumed.

**Already in flight (don't duplicate):** `docs/modules/ACCOUNTING_Build_Plan.md` — Accounting module rebuild as a standalone Zoho-Books-grade app on its own subdomain, SSO'd to CBOP. This is the template/precedent for "existing module → full SaaS app." See memory `project_accounting_rebuild`.
